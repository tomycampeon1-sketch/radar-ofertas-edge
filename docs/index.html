Cómo funciona

  1. Base de datos compartida. Es el archivo docs/data/db.json de este repositorio. Guarda el último precio de cada producto en cada tienda, el historial y las ofertas detectadas.
  2. Actualización automática. Cada 6 horas GitHub revisa las tiendas y actualiza la base (en Argentina: 3:17, 9:17, 15:17 y 21:17, con algunos minutos de demora).
  3. Esta página lee la base y muestra el comparador, las ofertas y todos los precios.
  4. La extensión de Edge lee la misma base cada hora y te avisa con una notificación cuando hay una oferta nueva. Además revisa desde tu compu las portadas de las tiendas por eventos (Hot Sale, CyberMonday, cuotas).

De dónde salen los precios

Los marcados al día los leyó el radar en la tienda. Los marcados nota vienen de la investigación (notas periodísticas del 8 al 21 de noviembre de 2026) y quedan como referencia hasta que el radar consiga un precio real. Los viejo son de una lectura anterior porque la tienda no respondió esta vez.

Contado contra cuotas

"Sin interés" casi siempre se cobra sobre un precio más alto que el de contado. El recargo es cuánto más pagás en total en cuotas comparado con el mejor precio de contado. El valor actual de las cuotas descuenta la inflación: si es menor que el contado, las cuotas te convienen aunque sumen más.

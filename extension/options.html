Base compartida con la página

La página del radar guarda los precios de todas las tiendas en una base que GitHub actualiza cada 6 horas. La extensión la lee cada vez que revisa y te avisa de las ofertas nuevas que encuentre (bajas de precio, mínimos históricos, descuentos y cuotas sin interés). Abrir la página

Aportar precios a la base desde esta compu

Algunas tiendas (Frávega, Venex, Full H4rd…) bloquean a los servidores de GitHub pero no a tu navegador. Si activás esto, cada 3 horas la extensión lee esas tiendas desde Edge y guarda los precios en tu repo. En la próxima actualización aparecen en la página y en la base, marcados "desde tu compu".

Cómo crear la clave de GitHub (2 minutos)
  1. Entrá a github.com/settings/personal-access-tokens/new.
  2. Token name: "Radar de Ofertas". Expiration: 1 año (o lo que prefieras).
  3. Repository access: "Only select repositories" y elegí radar-ofertas-edge.
  4. Permissions > Repository permissions > Contents: "Read and write". No hace falta nada más.
  5. Tocá Generate token, copiá la clave (empieza con github_pat_) y pegala acá abajo.

La clave queda guardada solo en este Edge y solo puede tocar ese repo.
